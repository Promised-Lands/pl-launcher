# Promised Lands – launcher

Launcher serwera RedM **Promised Lands**. Instaluje i konfiguruje głos (Mumble z wtyczką Promised Lands), a potem uruchamia grę połączoną z serwerem.

## Pobieranie

Najnowsza wersja jest w zakładce [Releases](https://github.com/Promised-Lands/pl-launcher/releases/latest). Pobierz plik `PromisedLands.Launcher.Player-win-Setup.exe` i uruchom go. Instalacja nie wymaga uprawnień administratora.

Wymagania: Windows 10 lub 11 (64-bit) i zainstalowany RedM.

W tym repozytorium są tylko gotowe wydania launchera, bez kodu źródłowego.
